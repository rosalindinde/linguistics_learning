# Linguistics Learning for Rosalind

可复用的语言学精读 Skill，基于 Rosalind 对教材逐段教学的要求，以及 9.5–9.8 精读后的完善意见。

## 内容

- `SKILL.md`：Skill 主指令。包含原文核对、四模块教学法、并列概念关系分析、实验设计讲解、交互规范、自检清单。
- `references/concept-comparison-example.md`：以 acculturation / assimilation / amalgamation 为例展示如何解释并列概念之间的关系。
- `references/paragraph-analysis-example.md`：以 colour words 为例展示如何逐段解释复杂论证，而非只总结标题。

## 使用

将 `SKILL.md` 连同 `references` 目录放在支持 Skill 文件夹的环境中；若环境支持导入 Skill 压缩包，可使用同名 `.zip`。不支持自定义 Skill 的环境，也可以直接复制 `SKILL.md` 的指令作为教学工作流。

> 此包是一个可供导入的 Skill 文件，不代表它已经自动安装到任何账号或插件目录。
