# Worked example: how to read 9.5.3 Colour words without replacing the text with its heading

## Scope

Section 9.5.3, p.132, **two original paragraphs**. This is an illustration of the teaching procedure, not a replacement for checking the actual edition and page photograph in the current conversation.

## First paragraph: original order

1. Opening claim: 虽然人类面对的可见光谱具有共同的物理基础，不同语言不必以同一方式划分色谱。解释 **entail**（必然蕴涵）、**colour spectrum**（色谱）、**hue**（色相）；分清视觉能力与词汇类别。
2. Two/three basic colour terms: 为什么可以说某语言只有两个或三个**基本**颜色词，却不表示该语言只能谈论两三种颜色？引入基本颜色词的定义边界，不将英语的 black/white 字面义硬套到另一语言。
3. **Semantic range** vs **focal point**：前者是类别词所覆盖的颜色范围，后者是类别中最典型的颜色。一个词可以涵盖红—橙—黄的若干范围，却以红色附近为典型焦点。两者不是同义词。
4. Order and regularity claim: 作者描述基本颜色词出现的序列和规律性。说明这是跨语言的经验概括而非逻辑定理；应查其学术来源与后续修订。看到原文绿色重复出现在不一致的顺序描述中，不要无声修订。
5. Human perception: 作者从“词汇分类并非完全随机”提出“可能受到共同视觉能力约束”的解释。**模式存在 ≠ 机制已被证实**。最后 `If this is true` 是有条件的进一步推测，不能读成已证明的事实。

## Second paragraph: original order

1. 过渡：作者从颜色词覆盖的基本类别转向颜色词的**附加联想与固定表达**。说明两段并非同一研究问题。
2. **green with envy / green-eyed / greenhorn**：逐个解释表达的实际意思；注意 greenhorn = 无经验者，而非嫉妒的人。
3. **blue mood / blue blood / blue book**：逐个解释不同的惯用义，不归纳出“蓝色永远等于悲伤”。
4. Evidence test: 英语内部的多个含颜色词表达，可以支持“颜色词有多种惯用附加义”；若作者声称跨文化存在系统差异，仍需比较另一语言，不能仅凭英语例证推出。

## Relationship between paragraphs (explicitly marked as instructor synthesis)

“以下是我按研究对象作出的整理：第一段关心 basic colour terms 如何划分颜色空间，以及这种划分可能受到哪些共同约束；第二段关心颜色词在惯用表达中的联想意义。这个区分来自两段所使用的例证和关键词，**并非作者提出的两层理论**。”

## Avoid

- “第一段说颜色分类不同，第二段说颜色联想不同。”——这只是目录级摘要，不能替代讲解。
- 不解释 basic、semantic range、focal point、entail，就直接讲跨语言颜色实验。
- 把教材没有的俄英或希英实验当作教材自己的例证。
- 把泛泛的文化相关性说成语言影响知觉的实证证明。
